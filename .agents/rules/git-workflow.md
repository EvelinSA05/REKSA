# Git Commit & Push Workflow

- **Granular Commits**: Setiap kali selesai mengedit kode atau menambahkan fitur/perbaikan, selalu buat commit secara terpisah dan granular (per file atau per fungsi/tujuan kecil). Jangan menumpuk banyak perubahan dalam satu commit besar.
- **Immediate Push**: Segera jalankan `git push` setelah setiap commit dibuat agar kontribusi tercatat di remote GitHub secara bertahap dan konsisten.
- **Clear Commit Messages**: Gunakan pesan commit yang deskriptif dan jelas sesuai perubahan yang dilakukan.
